(3) “Create New File” Flow
Route: could be `/files/new` or handled via a modal/stepper inside `/dashboard`.

Steps:

Step A – Basic info:
- Ask user for:
  - File name (required).
  - Optional description.
- Provide a button to go to student import step.

Step B – Add Students:
- Two options:
  1. **Manual entry**:
     - Start with at least one row with inputs:
       - Student Name (required)
       - Student ID (required)
     - Allow adding more rows (Add Student button).
     - Validate that at least one row has both name and ID before proceeding.
  2. **CSV upload**:
     - Allow uploading a CSV file.
     - At minimum, CSV should support “name” and “id” columns.
     - Allow additional columns (e.g., section, email) and keep them in the student data structure.
- After uploading/entering:
  - Show a **preview table of all imported students** (and columns).
  - Let the user **confirm** the data before creating the grade sheet.
  - Only after confirmation, create the grade file and redirect to the grading page.

Implementation notes:
- Use a CSV parsing library (PapaParse / react-papaparse) on the client side.
- Handle basic CSV errors gracefully and show a friendly message.

(4) Grading Page (Core Feature)
Route: e.g., `/files/[fileId]`

Purpose:
- Spreadsheet-like view where each row is a student and each column is a grade or computed column.

Initial state:
- Rows: students from the previous step (name, ID, and any extra fields).
- Columns:
  - Start with a couple of default grade columns (e.g., “Assignment 1”, “Midterm”, etc.) or start with none and let the user add them.

Column types:
- Each column has:
  - ID
  - Title (user-editable)
  - Type (one of):
    1. **Input** – normal grade column where user types numbers manually.
    2. **Sum** – computed column that sums selected other columns per row.
    3. **Max** – computed column that takes the max of selected other columns per row.
- When user adds a new column:
  - Ask for:
    - Column title (string).
    - Column type (Input / Sum / Max).
    - For Sum or Max, allow selecting which existing columns are included.
- For each row (student):
  - Input columns: user can type numeric values.
  - Sum/Max columns: values are auto-calculated and not directly editable.

Behavior:
- Table should update values immediately when the user changes grades in any Input column.
- Use React state to hold:
  - List of students.
  - List of columns and their metadata.
  - All grade values.
- Implement **auto-save**:
  - On every change (or debounced), automatically persist the file data to local storage or a simple storage layer.
  - Also provide a manual “Save” button for user confidence.
- Allow the user to:
  - Rename columns and update their types if possible.
  - Add more columns at any time.
  - Optionally hide/remove columns (you can handle delete carefully so it doesn’t break formulas).
